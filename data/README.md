# Dataset

This project uses the **IMDB Movie Review Dataset**, containing 50,000 movie reviews labeled as either positive or negative.

The dataset is not included in this repository.

### Dataset Source

The dataset can be downloaded from Kaggle:

https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

After downloading the dataset, place the file in this directory:

    data/IMDB Dataset.csv

### Dataset Structure

The dataset contains two columns:

- `review` — The movie review text
- `sentiment` — The sentiment label (`positive` or `negative`)

### Dataset Distribution

- **25,000 positive reviews**
- **25,000 negative reviews**
- **50,000 total reviews**
